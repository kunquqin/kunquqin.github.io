# 视觉设计中英文切换

- 范围：视觉设计师与创意视觉设计师两个首页，各展示雷朋、巨量引擎、吃货豆、E宝、幻星、得物、iPhone 17 Pro、SU7、嘟记豆、喵息，共10个项目。旧视觉探索详情保留双语与直接访问，但不再出现在首页及项目循环；其他岗位和通用项目路径不启用。
- 文案：`source/_data/visual_i18n.json`，以原中文完整文本节点为键、英文为值。中文源文案改变时需同步词典；图片内文字保留原图。
- 模板按 `visual_bilingual(page)` 加载按钮、词典与脚本；无JS仍可阅读原中文，按钮隐藏。
- 优先级：URL `?lang=en` / `?lang=zh`，其次本地语言偏好，默认中文。点击按钮保存至 `visual-portfolio-language`，只对视觉岗位生效。
- 切换保留原DOM结构、事件和样式；MutationObserver只处理新增/更新文字及可翻译属性，不监听动画样式。轮播无障碍标签同步当前语言。
- 跨页面链接携带语言参数；页内 `#` 锚点保持原样，兼容章节导航和滚动效果。切换后刷新滚动测量。
- 幻星的中文亿/万单位随数值一同换算为B/K，避免数值含义改变。

验证：运行 `npm run build` 后执行 `python tests/visual_language_coverage.py` 检查两个岗位22页文案覆盖和岗位隔离。浏览器另检查语言往返、刷新、详情/返回/下一个项目、弹窗、轮播和移动端布局。

创意视觉岗位：`/creative-visual-designer/`，复用`portfolio_mode: visual`并以`portfolio_variant: creative`区分，保持布局/交互一致；两岗位均有交互探索（iPhone、SU7）和独立产品（嘟记豆、喵息）分组。项目返回和下一项目使用各自岗位路径；两岗位共用语言偏好，链接仅在当前岗位内携带语言。

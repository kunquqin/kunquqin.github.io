## 面试前需要补实的证据

1. 亲自负责的具体角色、服装或资产，明确独立制作/共同制作/指导验收边界。
2. Maya、ZBrush、3ds Max的实际使用深度。3ds Max尚不写入页面。
3. AI生成白模/粗贴图是否真实做过，所用工具、输入输出及后续人工修正。当前只写已有的概念探索。
4. 如有材料，补原画与最终角色对照、模型线框/拓扑、材质拆解、多视角及迭代前后对比。
5. 游戏视角识别度、绑定变形、引擎性能优化、原画独立设计能力均需具体作品支撑，当前不新增这些能力声明。

当前最大缺口是亲手制作的证据，而不是更多岗位关键词。确认上述信息后再提高制作能力描述的具体程度。

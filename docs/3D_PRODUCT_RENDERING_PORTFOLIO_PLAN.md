# 3D 产品渲染作品集：任务与验收清单

更新日期：2026-09-03  
工作原则：按项目顺序推进；当前项目未通过验收，不进入下一个项目。

## 0. 项目目标

在首页 `3D` 分类中新增三个完整案例，用不同尺度的产品证明三类能力：

1. 精密产品：旗舰智能手机产品视觉化
2. 产品体系：高端个人科技产品组合
3. 大型工业产品：小米 SU7 汽车视觉化

最终交付不是海报拼图，而是三个独立、可响应式浏览的案例页面。产品图片负责视觉表现，标题、参数、页码和说明统一由网页代码排版。

## 1. 全局验收标准

### 1.1 作品可信度

- [ ] 明确标注项目属性：个人视觉化练习 / 非官方商业委托
- [ ] 真实品牌项目不虚构合作关系、上线结果或商业数据
- [ ] 不把纯 AI 生成图片描述为独立完成的 3D 建模与渲染成果
- [ ] 页面必须展示可验证的制作过程：白模、线框、材质、灯光或渲染通道至少三类
- [ ] 同一项目中产品结构、比例、颜色和关键零件保持一致

### 1.2 视觉质量

- [ ] 主视觉达到商业产品摄影质感，主体轮廓清楚
- [ ] 金属、玻璃、塑料、织物、车漆等材质可被明确区分
- [ ] 无明显结构畸变、穿模、悬浮错误、错误反射和塑料感
- [ ] 不出现乱码、错误 Logo、水印、噪点和无意义装饰
- [ ] 每屏只有一个核心视觉任务，留白和文字层级稳定
- [ ] 三个项目属于同一作品集系统，但各自具有独立色彩性格

### 1.3 页面体验

- [ ] 桌面端 1440px、1280px 无遮挡、溢出或异常换行
- [ ] 平板端 768px 信息顺序正确
- [ ] 移动端 390px 主体不被裁切，文字和图像节奏合理
- [ ] Hover 交互不造成布局位移；触屏设备无需 Hover 也能读取信息
- [ ] 图片使用合理尺寸与压缩格式，首屏加载速度可接受
- [ ] 图片包含准确替代文本，文字对比度满足阅读要求

### 1.4 统一页面结构

- [ ] Hero：项目名称、类别、职责、软件、年份与主视觉
- [ ] Intent：项目目标、视觉策略与镜头语言
- [ ] Hero Rendering：核心商业画面
- [ ] Detail：关键结构与微距材质
- [ ] Material / Lighting：材质与布光逻辑
- [ ] Process Evidence：白模、线框、通道或后期过程
- [ ] Atmospheric Finale：氛围画面与项目收束
- [ ] Next Project：明确的下一案例入口

## 2. Project 01：旗舰智能手机产品视觉化

### 2.1 定位

证明精密硬表面产品、玻璃与金属材质、镜头模组细节和棚拍布光能力。若使用 iPhone 17 Pro Max 名称，外观必须建立在可靠参考或准确模型上；不能使用结构近似但细节错误的产品冒充真实机型。

### 2.2 任务清单

#### A. 方向与基准

- [ ] 确认项目名称：真实机型视觉化或原创旗舰手机概念
- [ ] 收集正面、背面、侧面、镜头、按键和材质参考
- [ ] 确定机身颜色、背景色、主光方向和镜头焦段
- [ ] 先完成一张无文字产品基准图，锁定后再延展其他镜头

#### B. 核心素材

- [ ] 01 Hero Shot：悬浮三分之二视角
- [ ] 02 Camera Detail：镜头、玻璃与金属过渡
- [ ] 03 Edge Detail：边框、按键和屏幕边缘
- [ ] 04 Material Study：玻璃、金属、屏幕反射
- [ ] 05 Process：白模 / 线框 / 灯光 / 渲染通道
- [ ] 06 Atmospheric Shot：暗色轮廓光收尾
- [ ] 为 Hero 与重点画面准备移动端构图

#### C. 页面开发

- [ ] 新建独立项目详情页与样式作用域
- [ ] 完成 5–6 个内容段落及桌面排版
- [ ] 完成移动端重排和图片裁切规则
- [ ] 增加首页 `3D` 分类入口与封面

### 2.3 Project 01 验收门槛

- [ ] 六张素材看起来是同一台手机
- [ ] 镜头数量、位置、按键和边框结构无明显漂移
- [ ] 至少三类过程证据可证明制作方法
- [ ] Hero、微距、材质和氛围四类视觉任务区分明确
- [ ] 页面在 1440 / 1280 / 768 / 390px 通过检查
- [ ] 用户确认：`Project 01 OK`

> 只有以上项目全部通过，才进入 Project 02。

## 4. Project 03：Xiaomi SU7 Automotive Visualization

### 4.1 定位

证明大型硬表面产品、复杂曲面、汽车漆、轮毂灯组、座舱材质、环境反射和动态镜头能力。页面标注为个人视觉化练习，不暗示小米官方合作。

### 4.2 任务清单

#### A. 方向与基准

- [ ] 收集 SU7 外观、轮毂、灯组、座舱和材质参考
- [ ] 明确车型版本、车漆颜色和轮毂方案
- [ ] 建立统一车辆基准，避免不同画面结构漂移
- [ ] 确认棚拍与夜间动态两套灯光语言

#### B. 核心素材

- [ ] 01 Exterior Hero：三分之二前侧低机位
- [ ] 02 Body Surface：腰线、曲面和汽车漆
- [ ] 03 Performance Detail：轮毂、刹车与灯组
- [ ] 04 Rear Detail：尾灯和尾部曲面
- [ ] 05 Interior：方向盘、中控、座椅和氛围灯
- [ ] 06 Process：白模 / 线框 / 灯光 / 渲染通道
- [ ] 07 Driving Atmosphere：城市夜景或隧道动态
- [ ] 为 Hero 与动态画面准备移动端构图

#### C. 页面开发

- [ ] 新建独立项目详情页
- [ ] 以横向大图建立汽车视觉尺度
- [ ] 控制速度效果，不以运动模糊掩盖结构
- [ ] 增加首页 `3D` 分类入口与封面

### 4.3 Project 03 验收门槛

- [ ] 所有画面车型、车漆、轮毂和内饰版本一致
- [ ] 车身曲面连续，轮胎接地与环境反射可信
- [ ] 夜景画面不过曝，灯组与车身轮廓均可辨识
- [ ] 至少三类过程证据可证明制作方法
- [ ] 页面在 1440 / 1280 / 768 / 390px 通过检查
- [ ] 用户确认：`Project 03 OK`

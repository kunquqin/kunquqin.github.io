# 软件图标来源

2026-09-23 下载，保存至 source/images/software-logos，仅视觉岗位技能栏使用。

- Blender、Cinema 4D：Simple Icons v11，https://cdn.jsdelivr.net/npm/simple-icons@11/icons/ （blender.svg、cinema4d.svg）。
- Maya、Photoshop、Illustrator、After Effects、Figma：Devicon，https://github.com/devicons/devicon/tree/master/icons 。
- Claude、Cursor、ComfyUI、Midjourney、OpenAI：LobeHub icons-static-svg，https://www.npmjs.com/package/@lobehub/icons-static-svg 。Codex使用OpenAI品牌标识。
- ZBrush：https://img.icons8.com/color/96/zbrush.png ，来源 https://icons8.com 。
- 商标归各品牌所有，保留原标识，展示尺寸统一26px；单色SVG使用CSS浅色处理适配深色背景。
